## Columns

| Column | Meaning |
|---|---|
| `Part number` | HIWIN-type part number, e.g. `KK6010P-400A1-F0` |
| `Size` | frame size: KK50 / KK60 / KK86 |
| `Lead` | screw lead in mm |
| `Grade` | `C` (Normal) or `P` (Precision) |
| `Rail` | rail length in mm |
| `Max stroke (1 block)` | maximum stroke with one block, where published |
| `KINX build` | the KINX model that matches the mounting dimensions |
| `Quote` | how to price it |

## Read this before ordering against the table

The part numbers and the `Max stroke (1 block)` values reproduce what the manufacturer publishes.
They are a starting point for a drawing check, **not** a guarantee of interchangeability.
Combined height, hole pitch and thread, motor flange and coupling must be confirmed on the
supplier's drawing before a purchase order. Where a cell says `confirm on drawing`, no published
value exists.

## Scope — what is not here

KK40, KK100 and KK130 are not built by KINX and are absent. Strokes above 1310 mm are quoted as
custom bodies rather than part-number matches. Belt-driven and aluminium-profile modules use a
different numbering system.
